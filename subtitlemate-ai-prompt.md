# SubtitleMate AI Design Prompt

## Product Name

SubtitleMate

## Product Type

Chrome Extension

## Product Positioning

SubtitleMate is a lightweight Chrome extension that automatically enables YouTube subtitles and translates them into the user's preferred language.

It helps users watch international content, educational videos, tutorials, and podcasts without repeatedly opening subtitle settings.

Core idea:

"Set it once, watch forever."
