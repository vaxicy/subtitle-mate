## Features

- **Auto captions** — captions are enabled automatically when a YouTube video opens.
- **Auto translation** — translate captions into the language you choose in the popup.
- **Fixed playback speed** — every video starts at your preset rate.
- **Caption mode & target language** — use translated captions in your chosen language, or the English auto-generated track.
- **Remembered settings** — preferences are stored and applied on every video.
- **Configurable retries** — caption application retries up to 20 times (default 5).
- **Optional auto reload** — reloads the watch page once if captions keep failing to apply.
- **Bilingual UI** — English and Simplified Chinese interface.
- **YouTube only** — lightweight and focused on YouTube watch pages.

## 功能

- **自动字幕** — 打开 YouTube 视频时自动开启字幕。
- **自动翻译** — 将字幕翻译成你在弹窗中选择的语言。
- **自动播放速度** — 每个视频自动套用你预设的播放速度。
- **字幕模式与目标语言** — 使用翻译字幕（可选目标语言），或直接启用英语（自动生成）字幕。
- **记住偏好** — 设置自动保存，并在每个视频上应用。
- **可配置重试次数** — 字幕应用失败时自动重试，最多 20 次（默认 5 次）。
- **可选失败自动刷新** — 多次重试仍失败时自动刷新一次播放页。
- **中英双语界面** — 界面支持简体中文与 English。
- **仅用于 YouTube** — 轻量、专注于 YouTube 播放页。

---

## How to use

1. Install SubtitleMate for YouTube from the Chrome Web Store.
2. Open any YouTube video.
3. Click the SubtitleMate for YouTube icon in the toolbar.
4. Turn on **Auto Captions**, then choose a caption mode, a target language and a playback speed.

## 使用方法

1. 从 Chrome Web Store 安装 SubtitleMate for YouTube。
2. 打开任意 YouTube 视频。
3. 点击工具栏中的 SubtitleMate for YouTube 图标。
4. 开启**自动字幕**，选择字幕模式、目标语言与播放速度。

## Privacy

SubtitleMate for YouTube does not collect, store, or transmit any personal data. Your language preferences are saved locally in your browser via Chrome Storage. No remote servers are used.
